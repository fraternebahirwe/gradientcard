## ✨ Features & UI Highlights

- **Overall Result Panel:** Displays an aggregated score (`80 / 100`), percentile feedback (`Great`), and comparative performance metrics.
- **Category Summary Breakdown:**
  - ⚡ **Reaction:** Dynamic score breakdown (`80 / 100`).
  - 🧠 **Memory:** Dynamic score breakdown (`92 / 100`).
  - 💬 **Verbal:** Dynamic score breakdown (`61 / 100`).
  - 👁️ **Visual:** Dynamic score breakdown (`73 / 100`).
- **Inline Vector Graphics:** Clean, resolution-independent SVG icons embedded directly for each score category.
- **Responsive Layout:** Multi-panel grid/flexbox component that transitions smoothly from desktop dual-card view to mobile single-column view.

---

## 🛠️ Built With

- **HTML5:** Semantic layout using `<main>`, `<section>`, `<ul>`, and inline `<svg>` elements.
- **CSS3:** Custom gradient backgrounds, circular badges, card layouts, and button hover states (`gradient.css`).
